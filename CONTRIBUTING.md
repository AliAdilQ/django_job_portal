# Contributing

Follow the setup in the README, then run `python manage.py test` and `python manage.py check` before submitting a pull request. Keep views small, enforce ownership on private resources, and reuse existing templates and design tokens.

Describe the problem, resulting behavior, and validation in your pull request. Include real screenshots for visible changes and migrations for model changes. Never commit `.env`, uploaded resumes, virtual environments, or the local database.

Report bugs with reproduction steps, expected behavior, environment details, and relevant errors. Use fictional data when sharing examples.
